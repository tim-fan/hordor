{% comment %} Multi-photo capture widget. Works around a mobile browser limitation: tapping a `capture="camera"` file input a second time REPLACES the FileList instead of appending to it, so only the last photo taken ends up submitted. This accumulates captured files in JS instead, shows a thumbnail immediately, and syncs them into the real `name="photos"` input the form submits. {% endcomment %}
